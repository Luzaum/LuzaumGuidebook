# Relatório dos modelos clínicos do Receituário

Data da atualização: 2 de agosto de 2026.

O Receituário mantém quatro modelos clínicos globais ativos. O cadastro é funcional, mas não representa validação clínica; as fontes estruturadas ainda devem ser revisadas quando indicado.

## Modelos ativos

| ID | Modelo | Espécie | Estado |
|---|---|---|---|
| `seed-infectologia-esporotricose-gatos` | Esporotricose — Gatos | Gato | Funcional com fontes pendentes |
| `seed-infectologia-esporotricose-caes` | Esporotricose — Cães | Cão | Funcional com fontes pendentes |
| `seed-infectologia-cinomose-caes` | Cinomose — Cães | Cão | Funcional com fontes pendentes |
| `seed-infectologia-erliquiose-anaplasmose` | Erliquiose/Anaplasmose — Cães | Cão | Funcional com fontes pendentes |

## Modelos aposentados

- Parvovirose — Cães — Protocolo hospitalar
- Parvovirose — Cães — Protocolo ambulatorial
- Gastrite Aguda / Gastroenterite
- CardioB2

Os modelos aposentados não são exibidos mesmo que ainda existam em cache ou como registros antigos no banco. Modelos globais continuam protegidos contra exclusão pelo usuário; modelos próprios podem ser selecionados e excluídos em lote pela interface.
